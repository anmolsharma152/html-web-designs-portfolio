## 4. ⚡ Interactive Motion & 3D WebGL Engineering

### 3D Perspective Card Tilt Physics
```javascript
document.querySelectorAll('.tilt-card').forEach(card => {
  card.addEventListener('mousemove', (e) => {
    const rect = card.getBoundingClientRect();
    const x = e.clientX - rect.left - rect.width / 2;
    const y = e.clientY - rect.top - rect.height / 2;
    const rotateX = (-y / rect.height) * 12;
    const rotateY = (x / rect.width) * 12;
    card.style.transform = `perspective(1000px) rotateX(${rotateX}deg) rotateY(${rotateY}deg) scale3d(1.02, 1.02, 1.02)`;
  });

  card.addEventListener('mouseleave', () => {
    card.style.transform = `perspective(1000px) rotateX(0deg) rotateY(0deg) scale3d(1, 1, 1)`;
  });
});
```

## 6. 🎓 Production Best Practices & Performance Optimization

1. **Hardware Acceleration**: Always use `transform: translate3d()` or `will-change: transform` for elements animated on scroll or mouse move to offload rendering to GPU composite threads.
2. **Backdrop-Filter Scoping**: Limit `backdrop-filter: blur()` to top-level cards or fixed navbars. Avoid applying blur filters to hundreds of child elements to prevent frame drops on mobile devices.
3. **Contrast Compliance (WCAG 2.1)**: Ensure body text on dark glass cards has a minimum contrast ratio of `4.5:1` against the backdrop (`#f8fafc` or `#cbd5e1`).
